# 2026-11-18: M0, scaffold and guardrails

**Goal:** a clean, public-safe project foundation before any game code.

**Done**
- Created the project in its own folder with its own git repo (not a parent or home folder).
- Set a repo-local commit identity using a GitHub `noreply` address.
- Added a strict `.gitignore` (env files, editor and OS files, local AI-tool config) and a `.env.example` with placeholders only.
- Wrote `scripts/check-privacy.mjs`. It scans tracked files and git history for home-directory paths, the local username and hostname (read at runtime, so the script holds no personal data), non-noreply email addresses and common secret patterns. It prints only a masked fragment of any match so findings are not re-leaked into CI logs.
- Wired the check into a pre-commit hook (`.githooks/`) and into CI.
- Scaffolded a TypeScript project: React + Vite client, Node + Socket.IO server stub with a health endpoint, shared constants, and a Vitest smoke test.
- Turned production source maps off, because they can embed absolute local paths.

**Decisions:** see [docs/decisions/](../decisions/).
